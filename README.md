Instructions to run the code:
Clone the repository to your local system using git clone <repository-link> and navigate to the project folder.
Install the required libraries using pip install tensorflow numpy matplotlib opencv-python scikit-learn.
Ensure the dataset is placed in the correct path: C:\jenkins-ml\datasets\chest_xray with train, val, and test folders.
Verify the pretrained MobileNetV2 weights path in the script matches your local system.
Run the main training script using python train_model.py (or your script filename).
After execution, the trained model, graphs, confusion matrix, and Grad-CAM output will be saved in the outputs folder.
